# Как описать улицу

Улица, двор и дом — одна сцена. Двор — та же комната из `rooms[]`, только с
`open: true`: у него нет стен, потолка и перекрытия, есть только пол. Пример —
`specs/examples/street-two-houses.scene.json` (улица 40×12 м, два дома разной
высоты), маленький — `specs/examples/yard-house.scene.json`.

## Не делай улицу комнатой

Лужайка как комната `height: 30` со стенами-горизонтом даёт «обои»: швы на
углах, плоское небо и 25 м голой стены над домом. `check` ловит это:

- `ROOM_LOOKS_OUTDOOR` — комната выше 12 м или с тайлом стен про `horizon`,
  `sky`, `landscape`, `countryside`. Сделай её двором: `open: true` и `outdoor`.
- `WALL_HEIGHT_MISMATCH` — у двух закрытых комнат с общей стеной высоты
  расходятся больше чем на 3 м: над низкой комнатой голая стена.

## Двор (`open: true`)

```json
{ "id": "street", "level": "L0", "open": true,
  "shape": [[-20,-6],[20,-6],[20,6],[-20,6]], "floor": "cobble" }
```

- `height`, `walls`, `ceiling` не нужны.
- Ходить можно в пределах контура двора: по краю стоит невидимый забор.
- Двор с двором стыкуется без проёма — проход свободный по общему ребру.

## Дом: комнаты + `facade` + `roof`

Дом — обычные закрытые комнаты, примыкающие к двору общим ребром.

- Стена дом↔двор строится высотой комнаты дома (у двора высоты нет).
- `facade: "<material>"` — материал наружной грани этой стены. Без него
  снаружи тот же материал, что и `walls` внутри. Тайл фасада ложится на всю
  высоту стены: UV в метрах от пола до верха.
- `roof: { "material": "tiles", "kind": "gable" | "flat", "overhang": 0.4 }` —
  крыша над следом комнаты со свесом `overhang` м. `gable` — двускатная,
  конёк вдоль длинной стороны; `flat` — плита. Без `roof` дома не видно
  сверху, только потолок изнутри.
- Высоту делай одинаковой у соседних комнат одного дома, иначе
  `WALL_HEIGHT_MISMATCH`.

## Дверь во двор

Обычный `openings[]` на стене комнаты дома — у двора стены нет, проём режет
только стену дома:

```json
{ "id": "a_door", "kind": "door", "at": [0, -6], "width": 1.0, "height": 2.1, "sill": 0 }
```

Окно (`window`) на такой стене прорезает её насквозь; декаль окна
(`leaf.decal`) висит на обеих гранях — и в комнате, и на фасаде.

## Небо и земля: `outdoor`

```json
"assets": { "s_sky": { "kind": "sky", "aspect": "2:1", "prompt": "clear late-afternoon sky over a small town" } },
"outdoor": { "sky": "s_sky", "ground": { "material": "grass", "radius": 150, "fade": 40 } }
```

- `sky` — ассет вида `sky`: панорама 2:1 на куполе. Движок сам добавляет к
  промпту «equirectangular 360 panorama…» и убирает шов слева-справа. Пиши
  только что на небе и что на горизонте; людей не будет.
- `ground` — диск под всей сценой радиуса `radius` м, по краю на ширине
  `fade` м уходит в небо, поэтому горизонта-стены нет. `fade` ≤ `radius`.
  Диск лежит на 1 см ниже пола дворов.
- Свет снаружи — солнце и небесный hemi, его цвета берутся из панорамы.
- Без ассетов (`--assets none`) небо — градиент от `style.exterior`, земля —
  цвет её материала.

## Предметы: крупные, а не сотня мелких

Улицу делают узнаваемой несколько крупных предметов (дерево, фонарь,
скамья, колонны веранды), а не россыпь мелочи. Колонны и веранда у фасада
ставятся в двор (`room` = двор) снаружи стены.

Бюджет (Б1): ≤ 1000 треугольников на мелкий предмет (до 0,5 м), ≤ 5000 на
мебель (до 2 м), ≤ 8000 на крупный, ≤ 300 000 на сцену; точечных ламп ≤ 2 на
всю сцену (three.js считает каждую лампу в каждом материале, B21), во дворе тоже — свет даёт солнце.

## Россыпь (`scatter`): кочки, трава, камни на лугу

Много мелких копий одного ассета не кладут как `props`. В сцене есть массив
`scatter`: каждый элемент — `{assets, count, area, seed, avoid?}`.

- `assets` — id объектных ассетов; каждой копии seed выбирает один из них;
- `count` — сколько копий хочется; `area` — `[minx, minz, maxx, maxz]` в метрах;
- `seed` — целое: тот же seed даёт ту же раскладку; `avoid` — точки `[x, z]`
  (например `at` мест игры), от которых копии держатся не ближе 0.8 м.

Копии держатся не ближе 0.8 м друг от друга; высота копии 0.3–0.6 м. Если
`avoid` закрывает всю `area`, сборка падает с `SCATTER_EMPTY`; если все копии не
влезли, строится сколько влезло и в `build.json` пишется `SCATTER_FEWER`.
В `build.json` `scatter` — по одной записи на ассет, `transforms` —
`[x, y, z, yaw, scale]` на копию; страница рисует запись одним `InstancedMesh`.

```json
"assets": { "tuft": { "kind": "object", "prompt": "a small grass tussock" } },
"scatter": [{ "assets": ["tuft"], "count": 170, "area": [-20, -20, 20, 20], "seed": 7, "avoid": [[0, 0], [4, 2]] }]
```
