# Dreamer Home — витрина сабмита: готовые сцены (книга / фристайл) и «создать свою»

Версия 0.2 · 2026-11-04 · автор: Claude. Хозяин спит; его цель: «ui/ux для сабмита: список готовых сцен в режиме книга и фристайл + возможность создать свою; спек → критика luna → реализация → тесты → сабмит». Всё ниже, включая живую проверку, делает Claude.
**Дедлайн:** 20:00 ET (L178: официальный срок не сверен, берём ранний). Цель — код, тесты и живая проверка закоммичены до 16:00 ET, дальше только сабмит.

## Зачем

Сейчас у Dreamer нет входной двери. Каждая сцена запускается своей командой из терминала (`python3 -m make.play <run>`, `python3 -m place.serve <run>`), порт sim по умолчанию 8770 (`h0/make/play.py:239`). Лобби, меню или галереи в коде нет (поиск по `engine/`, `h0/`, `app/`). Для видео и README нужен один экран: видно наши сцены, выбираешь «как в книге» или «фристайл», заходишь, возвращаешься; там же можно придумать свою главу и посмотреть, как она ставится.

**Цель одной фразой:** один URL → карточки готовых сцен → в два клика ты внутри; там же «create your own».

### Граница обязательного (cut line)

Делается по порядку, каждая ступень сама по себе сдаётся:

1. **Обязательно:** витрина готовых сцен, запуск в режимах Book и Freestyle, iframe, «← Home», остановка процессов.
2. **Должно быть:** Create (а) «своя глава в нашем мире» с вводом текстом.
3. **Хорошо бы:** микрофон (Meta ASR) в Create; карточка (б) «дострой двор голосом».

Если к 14:00 ET ступень 2 не прошла живую проверку, панель Create показывает только (б) и готовые примеры, без кнопки Build.

## Что уже есть (сверено с кодом 11-04)

- **`make.play`** (`h0/make/play.py:208-249`):
  - CLI: `RUN [--freestyle] [--port P] [--static-port S] [--lang ru]`.
  - Без `--fake` поднимает статик-сервер над `RUN` и **печатает URL страницы движка первой строкой stdout**, ещё **до** `play()` (`play.py:228-234`): `http://127.0.0.1:S/<dist>/index.html?sim=http://127.0.0.1:P&stage=<rel>`. Поэтому URL — не доказательство, что сцена поднялась (см. п.4 решений).
  - Потом ждёт зрителя (`wait_viewer`) и висит до сигнала.
  - Путь книги в `stage.json` может быть относительным (`dream/books/...`, от `h0/`), поэтому cwd процесса — `h0/`.
  - Страница — `dist_of(run)` (`play.py:30-37`): поле `dist` из `stage.json`, иначе `world/run/dist`.
- **Режим на странице движка** (`engine/src/runtime/stage/index.ts:608-658`):
  - у книжного прогона кнопка «⚡ Фристайл [G]» шлёт `POST <sim>/freestyle`, переход только в одну сторону;
  - `--freestyle` начинает сразу фристайлом;
  - поле Tab (`operator.ts`) шлёт режиссёру `idea`, только во фристайле.
- **`place.serve`** (`h0/place/serve.py`):
  - двор Козбагарова 7, раздаёт `run/world/dist`, печатает `http://localhost:<port>/`;
  - диктовка: Meta ASR `asr()` `serve.py:30-46` принимает только WAV 16 кГц mono s16; `/wish` строит магазин ~2.5 мин;
  - защита (повторяем): Host только localhost/127.0.0.1, Origin если прислан — свой, обязательный не-simple Content-Type у POST (`_same_origin`, `serve.py:110-118`), пути через `_safe`.
  - WAV-кодировщик в браузере — `h0/place/host/dictate.js:44-81` (`wavOf`): ScriptProcessor → усреднение до 16 кГц → Int16.
- **`make`** (`h0/make/__main__.py`): `make "<промпт>" [--book DIR --scene ID] [--world DIR] [--run DIR] [--max-dollars N] [--fake]`.
  - Стадии: brief, refs, world, cast, story, stage, shotplan (`make/core.py:216-225`).
  - `--world DIR` — готовый мир (`scene.json` + `dist/`) линкуется, ничего не генерируется (`make/world.py:128-143`).
  - `make.json` в корне прогона атомарно переписывается: `{prompt, created, stages:{<id>:{status, started, finished, usd, error?}}}` (`core.py:338-352, 581-595`). **Общего статуса нет** — его выводит Home (п.6).
  - `cast` персонажей не создаёт, а проверяет `cast.json` + GLB в `<run>/cast.src/` (`make/cast.py:386-392`). L178: гости генерируют места и предметы, персонажи — готовый каст.
  - Книжная сцена может назвать комнату мира полем `room` (`make/stage.py:388-400`, `_scene_room`).
- **Seed-режим (`make "<промпт>"` без книги) для витрины не годится:** `sim.seed_start` (`h0/dream/sim.py:2842`) берёт актёров, придуманных режиссёром, а не каст. Тела из `cast.json` им не достанутся. Поэтому Create идёт через книжный режим (п.7).
- **Spark:** `make/book.py:37 spark_call(system, user)` — один вызов `muse-spark-1.3-contributor` (бесплатно), платная модель отклоняется, ключ через `keys.get("META")`.

## Решения

1. **Сервер Home**, пакет `h0/home/`, `cd h0 && python3 -m home [--port 8800] [--fake]`.
   - Bind только `127.0.0.1`.
   - stdlib (`ThreadingHTTPServer`), без новых зависимостей.
   - Статика `h0/home/static/` (`index.html`, `home.js`, `home.css`), без сборщика и без внешних CDN (офлайн).
2. **Каталог** `h0/home/scenes.json` (в git), три списка.
   - `scenes[]`: `id` (`[a-z0-9-]{1,40}`, не похожий на `home-…`), `title`, `subtitle`, `book` (строка «название by автор» или `null`), `blurb`, `kind` (`play` | `place`), `run`, `modes` ⊆ `[book, freestyle]` (у `place` ровно `[freestyle]`), `cover` (от `run`), `minutes`.
   - `worlds[]` — миры для Create: `id`, `title`, `dir` (мир: `scene.json` + `dist/`), `book` (книга-основа: `book.json` даёт стиль, рассказчика, описание персонажей и мест), `cast` (папка готового `cast/`), `who` (имена).
   - Все пути — относительно корня `meta/`. Резолвятся и должны лежать внутри родителя `meta/` (папки `anymove`, `meta-place` — соседи); иначе запись отклоняется.
   - Загрузчик `home/catalog.py` проверяет готовность:
     - `play` — `stage/stage.json` есть, страница `<run>/<dist_of>/index.html` есть, для `book` в `modes` — `stage.json.mode == "book"`;
     - `place` — `world/dist/index.html`;
     - `worlds` — `dir/scene.json`, `dir/dist/`, `book/book.json`, `cast/cast.json`.
   - Неготовая запись остаётся в API с `ready:false` и `why`; **страница её не показывает** (только в `?debug=1`).
3. **Два независимых слота процессов** (`home/session.py`):
   - **Scene** — одна играемая сцена. Новый `play` гасит прежнюю; `POST /api/stop` гасит только её.
   - **Build** — одна сборка Create. Вторая → 429. Сцену можно играть, пока идёт сборка.
   - Выход Home (Ctrl-C, SIGTERM, `atexit`) гасит оба слота.
   - Гашение: `SIGTERM` группе процессов (`start_new_session=True`), через 3 с `SIGKILL`.
   - Дочерний процесс: `sys.executable`, cwd `h0/`, stdin `/dev/null`, env наследуется + `PYTHONUNBUFFERED=1`.
   - stderr сразу в файл лога `h0/home/logs/<ts>-<id>.log` (`*.log` в `.gitignore`); stdout читает отдельный поток и дублирует в тот же лог. Так ни одна труба не забьётся.
4. **Запуск сцены:**
   - Порты свободные (bind 0 → номер → закрыть), sim и статик передаются явно.
   - Команды (фиксированные, путей из запроса нет):
     - `play` book — `[py, -m, make.play, <abs run>, --port P, --static-port S]`;
     - `play` freestyle — то же + `--freestyle`;
     - `place` — `[py, -m, place.serve, <abs run>, --port P]`.
   - Home ждёт первую строку stdout, начинающуюся с `http://`, до 20 с. Затем **1.5 с проверки жизни**: процесс жив → 200 `{url, id, mode}`.
   - Ошибки:
     - процесс умер до URL или в окне проверки → 502 `{error, log:[последние 5 строк]}`, группа гасится;
     - нет URL за 20 с → 504 с тем же телом, группа гасится.
   - Сцена, умершая позже, видна по `GET /api/session` → `{alive:false, log:[...]}`; страница поллит раз в 3 с, пока открыт iframe, и показывает плашку «the scene stopped» + хвост лога + «← Home».
5. **Внутри сцены:**
   - Home показывает полноэкранный `<iframe allow="autoplay; microphone; fullscreen; xr-spatial-tracking">`.
   - Поверх, слева сверху, маленькая плашка «← Home» (стоп Scene + назад) и ссылка «open in new tab».
   - Внутрь iframe Home ничего не пишет: другой порт, кросс-ориджин.
   - Звук: клик по карточке — жест в родителе, `allow="autoplay"` его делегирует. Если движку нужен свой клик — фиксируется в Д3 (лог) и в подсказке оверлея «click the scene to start».
6. **Статус сборки** (`GET /api/create/<run_id>`), выводится, а не читается:
   - `stages[]` в порядке `brief, refs, world, cast, story, stage, shotplan` (неизвестные стадии — в конце, отсутствующие — `waiting`): `{name, status, seconds, usd, error?}`.
   - `status`:
     - `failed`, если у любой стадии `failed` или этот Home запустил процесс и он вышел с кодом ≠ 0;
     - иначе `running`, если процесс жив;
     - иначе `ok`, если есть `stage/stage.json`;
     - иначе `failed` («build stopped»: например, сборка от прошлого запуска Home).
   - Плюс `usd` (сумма), `seconds` (с `home.json.created`, пока жив), `error` (первая упавшая стадия или код выхода), `prompt`, `title`.
7. **Create (а): «своя глава в нашем мире»** — главный путь Create.
   - Гость выбирает мир (карточка мира показывает его каст: «Mama & Mirai», «Holmes & Watson») и пишет, что происходит (8–600 символов): «Mirai finds a lost kitten in the meadow and wants to keep it».
   - `POST /api/create {world, prompt}`:
     1. Создаётся `meta/runs/home-<YYYYMMDD-HHMMSS>/` (абсолютный корень `catalog.RUNS`); `home.json {prompt, world, title, created}`.
     2. **Глава:** `home/write.py write_chapter(prompt, world)`, один вызов Spark contributor (`make.book.spark_call`). Вход: имена и описания персонажей мира из `book.json`, список комнат мира (`scene.json.rooms[].id`), стиль книги, правила формата. Ответ JSON `{title, room, paragraphs:[...]}`.
        - Проверки: `room` ∈ комнат мира; 4–14 абзацев; реплики только формата `"…" said <Имя>.` с именами из каста; каждый персонаж хотя бы раз.
        - Нарушение → одна повторная попытка с текстом ошибки, потом `failed` с причиной.
        - Пишется в `<run>/book/`: `book.json` (шапка книги-основы: стиль, `narrator_voice`, `pov`; `cast` — только персонажи мира; одна глава `chapter.txt`, сцена `{id: "custom", paras:[0, n-1], title, place: <place сцены-основы для этой комнаты или описание комнаты>, cast, aliases:{имя: имя}, room}`) + `chapter.txt` (абзацы через пустую строку).
     3. Копия `cast/` мира → `<run>/cast.src/` (без `marker.txt`).
     4. Сборка: `[py, -m, make, <prompt>, --book <run>/book, --scene custom, --world <abs world dir>, --run <run>, --max-dollars 1]`.
   - Шаги 2–4 идут в фоне в слоте Build: поток пишет главу, потом стартует `make`. Ошибка главы → `home.json.error`, статус `failed`.
   - Стадия `chapter` показывается первой в `stages[]` (из `home.json`: `chapter: {status, seconds, error?}`).
   - Ожидаемо: глава ~20–40 с, brief ~15 с, refs ~40 с, story ~30–70 с; итого 2–4 мин. Деньги: Spark contributor $0, Muse Image/SAM3D не вызываются (мир готовый), Fish — только при игре.
   - Готовая глава — в «Your scenes» (скан `RUNS/home-*` со `stage/stage.json`; title из `home.json`, иначе первые 60 символов промпта), режимы book и freestyle, как у наших сцен.
8. **Create (б): «дострой двор голосом»** — карточка-ссылка на `kozb7-yard` с подписью «hold Space, say what should open here — a shop grows into the house in ~2.5 min». Это тот же запуск `place`.
9. **Микрофон в Create (а)** (ступень 3):
   - кнопка «hold to talk»: `getUserMedia` → копия `wavOf` из `dictate.js` (16 кГц mono s16) → `POST /api/asr` (Content-Type `audio/wav`) → текст дописывается в поле;
   - отказ в доступе к микрофону или ошибка ASR → подпись под полем, ввод текстом остаётся;
   - запись < 0.5 с игнорируется.
10. **Деньги и доступ.**
    - POST проходит только при: Host `localhost`/`127.0.0.1`; Origin — если прислан, то свой (`http://localhost:<port>` или `http://127.0.0.1:<port>`); без Origin разрешено (как `place.serve`: curl и тесты); Content-Type `application/json` (`audio/wav` для `/api/asr`).
    - Иначе 403 `{error:"forbidden"}`.
    - GET с чужим Host → 403 (DNS rebinding).
    - Лимит тела: 4 КБ JSON, 20 МБ WAV → 413.
    - Промпт: управляющие символы → пробел, пробелы сжаты, обрезка до 600, меньше 8 символов → 400; идёт отдельным argv, без shell.
    - `--max-dollars 1` на сборку Create.
11. **`--fake`** (тесты и сухой показ, ни одного сетевого вызова):
    - Scene: `h0/home/testdata/fake_scene.py <url>` печатает URL заглушки `/fake/scene.html?id=..&mode=..` (её отдаёт Home только в fake) и висит.
    - Create: глава — фиксированная (`write.py` fake), сборка — `make … --fake`.
    - `/api/asr` возвращает фиксированный текст.
12. **Вид** (кадр видео 1280×720 — главный).
    - Тёплая ночная «книжная» тема: фон глубокий синий `#141a2e`, кремовый текст `#f3e9d2`, янтарный акцент `#f2b450`; заголовки — системный serif (Georgia/Iowan), текст — system-ui.
    - **Первый экран 1280×720:** слева сверху «Dreamer» + строка «Step inside a story — or dream up your own.»; под ней вкладки **Book · Freestyle · Create**; ниже ряд карточек (видно ≥3 целиком без прокрутки); внизу тонкая строка «Built with Meta: Muse Spark directs · Muse Image paints · SAM 3D builds · Meta ASR listens».
    - Карточка: обложка 16:9, название, подзаголовок, книга, 2 строки описания, бейдж длительности, одна главная кнопка вкладки («Read it» в Book, «Improvise» во Freestyle).
    - Freestyle-вкладка сверху поясняет одной строкой: «The book is only the start: the director and the characters improvise. Press Tab to whisper an idea.»
    - Create: слева выбор мира (2 карточки), справа поле, микрофон, Build; под ними прогресс сборки (стадии с галочками, секунды, «usually 2–4 min»); ниже «Your scenes».
    - Оверлей запуска «Opening the book…» со спиннером; ошибка → тост с `error` и хвостом лога.
    - 390 px: карточки в одну колонку, вкладки остаются видимыми, текст не обрезан.

## API (`h0/home/server.py`)

Все ответы — JSON, ошибки `{error, log?}`.

| Метод | Путь | Ответ |
|---|---|---|
| GET | `/`, `/static/*` | страница; путь вне `static/` → 404 |
| GET | `/api/scenes` | `{scenes:[{id,title,subtitle,book,blurb,kind,modes,minutes,cover_url,ready,why}], worlds:[{id,title,who}], mine:[{id,title,prompt,world,modes,cover_url}], session:{id,mode,url}\|null, building:run_id\|null, fake:bool}` |
| GET | `/api/session` | `{alive, id?, mode?, url?, log:[…]}` (лог — хвост последней сцены) |
| GET | `/cover/<id>` | обложка по id из каталога или `home-*` (только через карту id → путь); нет → 404 |
| POST | `/api/play` | `{id, mode}` → 200 `{url,id,mode}`; 404 неизвестный id; 400 режим не из `modes` или плохой JSON; 409 `ready:false`; 502/504 (п.4) |
| POST | `/api/stop` | `{}` → 200 `{ok:true}` (и когда нечего гасить) |
| POST | `/api/create` | `{world, prompt}` → 200 `{run_id}`; 400 плохой JSON / короткий промпт / неизвестный или неготовый мир; 429 сборка идёт |
| GET | `/api/create/<run_id>` | статус (п.6); `run_id` не `home-\d{8}-\d{6}` или нет папки → 404 |
| POST | `/api/asr` | WAV → 200 `{text, s}`; 502 `{error}` ошибка ASR |

## Фазы

- **Д1 — сервер.**
  - Код: `home/{catalog,session,write,server,__main__}.py`, `scenes.json`, `testdata/fake_scene.{py,html}`.
  - Тесты `h0/home/test_home.py` (unittest, без сети, временные папки):
    - каталог: валидная запись ready; отсутствующий run → `ready:false`; путь вне родителя `meta/` → отклонён; `place` без `world/dist/index.html` → `ready:false`;
    - `play` (fake) → URL; второй `play` гасит первый (pid мёртв); процесс, умерший до URL → 502 с логом; `stop`;
    - 404 чужой id; 400 режим; 403 чужой Origin; 403 без Content-Type; 403 чужой Host; 413 тело;
    - `write_chapter`: валидатор отклоняет чужое имя, неизвестную комнату, мало абзацев; книга, которую он пишет, проходит `make.brief`-проверку книги (`validate`/`load_book`);
    - `create` (fake) доходит до `ok`, появляется в `mine`; 429 на вторую; `run_id` с `..` → 404; `/cover` только по карте;
    - статус: упавшая стадия → `failed`; живой процесс → `running`; нет процесса и нет stage → `failed`;
    - выход Home гасит оба слота.
- **Д2 — страница.** `static/index.html`, `home.css`, `home.js`.
  - e2e `h0/home/e2e.mjs` (Playwright, уже стоит в `engine/node_modules`) против `python3 -m home --fake --port <free>`:
    1. Book: 4 карточки, Freestyle: 5;

## Риски

- **Фристайл вживую почти не гоняли** (L25, `make-debt.md:149`). Д3 смотрит ≥2 мин. Если зацикливается — вкладка остаётся, но с подписью «experimental» и коротким `minutes`.
- **Sherlock** живёт в worktree `meta-place`: фиксы камеры и сидения не слиты (L181, L184), и там работает другая сессия. Dist несёт свой `runtime.js`, sim — из `meta/h0`. Ломается в Д3 → карточка убирается, в сабмит-день не чиним.
- **iframe + звук:** если движку нужен свой клик, первый кадр без звука; фолбэк — подсказка и «open in new tab».
- **Глава от Spark** может быть слабой или ломать формат: есть валидатор + один повтор; в видео показываем проверенную главу.
- **`make --book` с книгой вне `dream/books`** не гонялся: проверяется первым же fake-тестом Д1. Если путь не проходит, книга пишется в `h0/dream/books/home-<ts>/` (в `.gitignore`).
