## Н10. постановка: модель-директор пишет мизансцену

Зоны: `h0/dream/book.py` (`score_scene`), `h0/make/story.py`, `h0/make/schema/**`, `h0/dream/sim.py` (`_book_step`: передача полей; `_load_book_plan` около строк 169–204: план сцены не теряет `start`; `_book_open_scene` около строк 1132–1140: шлёт событие `start` до первого `stage` или `line` сцены), `engine/src/runtime/bridge.ts` (пропускать события `stage` и `start`; сейчас мост пропускает только `line`, `narrator`, `touch`, `mode`, `story`, строки 32 и 44), `engine/src/runtime/stage/index.ts` (новый обработчик события `stage` с полями `{ms, who, action, place?, pose?, look?}` и события `start` с `{who, place, pose, offstage?}`; существующий обработчик `line` его не исполняет, поэтому `_book_step` шлёт `stage` отдельным событием перед `line`), `engine/src/runtime/stage/path.ts` (межкомнатный переход: `exit` идёт к двери своей комнаты и в `offstage`, `enter` ставит актёра у двери комнаты сцены и идёт внутрь; маршрут через соседнюю комнату не строится), тесты `h0/dream/test_book_stage.py` и `engine/test/stage-blocking.test.ts` (новые).

Решение пользователя (11-01): мизансцену решает модель-директор по тексту книги, движок исполняет, ручная правка в `book.json` побеждает. Сейчас `score_scene` делает биты из абзацев без постановки, а кто куда идёт угадывает `stageRegex` (журнал трений #22, #27: путает подлежащее).

Контракт:
- `score_scene(dir, scene_id, places=None, director=None)`. С `director` (Spark contributor, через уже существующую обёртку LLM в `h0/dream`) делается один вызов на сцену, ответ — JSON:
  - `start: [{who, place, pose, offstage?: bool}]`;
  - у каждого бита `stage: [{who, action, place?, pose?, look?}]`;
  - `action` из словаря `stay | come | goto | enter | exit | turn_away`; правило исполнения: `stay` — позиция и направление не меняются; `come` и `goto` — `place` обязателен, актёр идёт по `path.ts` и встаёт лицом к `look` (иначе по ходу); `enter` — `place` обязателен (дверь), актёр выходит из `offstage` и идёт внутрь; `turn_away` — позиция та же, поворот спиной к `look`, `place` не нужен; без обязательного `place` бит получает `stay` с предупреждением; `exit` — актёр идёт к двери по `path.ts`, проходит её и становится `offstage` (в squid_live это `walkOff`/`goDoor`, урок L74);
  - `pose` из словаря Н8;
  - `look` — имя актёра или места.
- В промпт идут: абзацы сцены, каст, имена мест с их `poses` и комнатой. Модель видит только имена, координаты считает код.
- Проверка ответа:
  - место не из банка → бит получает `stay`, в `score.json` пишется `warnings` с id бита;
  - поза, которой нет у места → `stand`;
  - битый JSON → один повтор того же вызова (журнал трений #32), потом сцена без постановки и предупреждение.
- Кэш по sha256 (абзацы + места + модель) в `story/`. Если в `book.json` у сцены есть свои `start` или `stage`, они берутся как есть: для каждого заданного руками поля (`start` или `stage` бита) модель не вызывается, недостающие поля генерирует модель; ключ слияния — `(id бита, who)`, ручная запись всегда побеждает ответ модели; неизвестный `who` в ответе → запись отбрасывается, неизвестный `action` → `stay`, оба с предупреждением и id бита; неизвестная цель `look` → без поворота, предупреждение; если задано всё, вызовов нет.
- Рантайм:
  - `start` ставит актёров на места и в позы Н9 сразу, без ходьбы, до первой реплики сцены (не «до первого кадра»: первый `stage.update` идёт раньше, чем подключается мост, `main.ts:295–300`);
  - `offstage` — актёр стоит у двери соседней комнаты, камера его не берёт (не входит в pivot режиссёра), пока `enter` не проведёт его через дверь по `path.ts`;
  - `stage` бита исполняется на старте бита;
  - `stageRegex` срабатывает, только когда у бита нет `stage`.
