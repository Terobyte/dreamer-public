### 0.1. Обращение по имени

Проблема: `h0/dream/sim.py` `_note_line` ищет в реплике полное имя из каста (`\bAshley Wilkes\b`). Когда каст записан полными именами (сцены от Wonder), обращение «Ashley, …» не засчитывается: в прогоне Twelve Oaks/Wonder `addressed` = 0 за весь прогон, адресат ответил на 1 из 9 обращений (в ручной сцене с короткими именами — 10 из 11). Очередь вырождается в круг по молчанию.

Контракт:
- Персонаж считается названным, если в реплике есть его полное имя **или любая его часть** длиной ≥ 3 буквы (`Ashley`, `Wilkes`, `Rhett`, `Butler`), как отдельное слово, без учёта регистра.
- Часть имени, общая для двух людей в касте (`O'Hara` у Gerald и Scarlett), сама по себе обращением не считается — только уникальные части.
- Ограничение `only` (шёпот) работает как раньше.

- [ ] тест: «Mr Butler, hush» → Rhett Butler назван; «the O'Hara girl» → никто не назван

### 0.3. Записки режиссёра копятся и повторяются

`sim.py:606` дописывает каждую записку в `self._notes[to]`, и все они идут в каждый промпт актёра до смены сцены. В Wonder-прогоне каждая записка сыграна дважды: Ретт дважды просит огня, Чарльз дважды зовёт Эшли «step outside», Джеральд трижды «Sumter fallen… to supper».

- [ ] записка, которую актёр сыграл (следующая его реплика после записки), уходит из промпта; в промпте только последняя несыгранная записка
- [ ] тест: записка → реплика актёра → следующий промпт этого актёра записку не содержит
- [ ] тест: две записки подряд до реплики → в промпте только вторая

### 0.4. Петля по словам, а не только по предметам

`loop_items` видит повтор только по предметам сцены и словам в ремарках. Эшли трижды сказал одно и то же («the North has factories… we have cotton»), и ни одно из этих слов не предмет сцены, поэтому повтор не пойман.

- [ ] в набор реплики добавить значимые слова произносимого текста (≥ 5 букв, не из `_LOOP_STOP`)
- [ ] тест: три реплики Эшли из `wonder.txt` → `loops_in` возвращает `factories`/`cotton`
- [ ] тест: старые тесты петли зелёные без правок
