# Задача: сидящий актёр садится на сиденье, а не в пол (SIT_DROP по телу)

Источник: стенд Кошакана, 11-02, урок L154, долг Н9 в `specs/make-debt.md`. Проверку в фильме делает хозяин после сдачи.

## Баг

`engine/src/runtime/stage/actors.ts:8` `SIT_DROP = 0.45`. Строка `actors.ts:206` опускает сидящего на 0,45 м при любом росте.
- Взрослому (1,65 м) это примерно впору.
- Ягнёнок Мирай (0,95 м, спальня Кошакана) уходит в пол: над изножьем кровати видна только макушка.

Колено и бедро уже гнутся правильно (`stage/pose.ts sitLegs`, на риге ягнёнка колено 79–84°). Сломана только высота.

Как воспроизвести:
1. В `anymove/runs/koshakan/world/home/book/bedroom/stage/stage.json` временно добавить `"start_pose": {"Mirai": "sit"}`.
2. Записать фильм: `cd h0 && python3 -m make.film <bedroom run> --out X.mp4 --max 300` (язык `en`: у спальни нет `score.ru.json`).
3. Вернуть `stage.json` как было. После проверки он не должен содержать `start_pose`.

## Решение

Опускание при посадке считается по телу, а не задаётся константой:

**опускание = высота таза в стойке − высота сиденья**

- **Высота таза:** мировая y таза или бедра рига в стойке относительно ступней. Мерить один раз при загрузке (кости бёдер уже ищет `findLegs` в `pose.ts`).
- **Высота сиденья:** `top` места, если он задан. Если `top` нет, то длина голени (колено→щиколотка рига), то есть бедро горизонтально, голень вертикально.
- **Запасной путь:** если у рига ног не нашлось (стенд-коробка), оставить пропорцию от роста, например `0.45 * height/1.7`, а не голые 0,45.

Где менять:
- `actors.ts` (константа → значение на актёра);
- место, где актёр садится (`teleport`/`touch` с `act "sit"`), чтобы туда передавалась высота сиденья.

Проверь в `index.ts:690` расчёт ступней и головы: он учитывает `SIT_DROP`, и после правки должен брать то же значение.

Новую публичную функцию добавить строкой в `research/feature_map.md`.

## Приёмка

1. **Сначала красный тест-свойство:** у сидящего актёра таз на высоте сиденья ±3 см, для роста 0,95 м и 1,65 м, с `top` у места и без него. На текущем коде тест должен падать на 0,95 м.
2. После правки тест зелёный. Полный `cd engine && npx vitest run` зелёный (красные репро `engine/test/bughunt2/*` исключены через `tools/gate_skip.txt`).
3. Фильм спальни с сидящей Мирай по шагам из «Как воспроизвести». На контакт-листе Мирай сидит на кровати, тело выше изножья, ноги согнуты. Положить лист «до | после» в отчёт.

## Не входит в задачу

- **Поза «лёжа» на кровати.** Её нет в данных: у `bed` спальни `kind: sit`, нет ни `top`, ни `lie`. Это отдельно, удочка 1 в L153.
- **`make.film` ждёт 300 с при падении `make.play`.** Это отдельный долг (L154, пункт 5).
- **Коммиты** короткие, строчными буквами, без префиксов и без AI-атрибуции.
