## Н8. постановка: банк мест знает позы и слоты

Зоны: `h0/make/stage.py` (`build_places` и всё, что пишет `places.json`), `engine/src/runtime/stage/places.ts`, `engine/src/runtime/stage/touch.ts` (`resolveTouch` принимает желаемую `pose`, занятость хранится по паре «место + поза», возвращается выбранная поза для Н9; предупреждения собирает `Stage.warnings(): string[]`, доступный тестам, `console.warn` остаётся дополнительно), `h0/make/test_stage_places.py` (расширять), новый `engine/test/stage-places-poses.test.ts`.

Фильм Кошакана v4: Мирай стоит у кровати, хотя по книге лежит в ней; в ванной должна стоять на табуретке. Сейчас `build_places` знает только `sit` (по последнему слову id из `SIT`) и `stand`. Банк мест по-прежнему строится из пропов сцены (это уже так), он получает позы.

Контракт:
- у места новое поле `poses: string[]` из словаря `lie | sit | stand_on | stand_at | door`. Поле `kind` остаётся как было (старые потребители не ломаются).
- Таблица слов по последнему слову id пропа (как `SIT`), в коде, одна на всё:
  - `bed`, `sofa`, `couch` → `["lie", "sit"]`;
  - `chair`, `bench`, `armchair` → `["sit"]`;
  - `stool`, `step` → `["stand_on", "sit"]`, если высота пропа ≤ 0.6 м, иначе `["sit"]`;
  - всё остальное → `["stand_at"]`;
  - двери → `["door"]`.
- `top`: высота верхней плоскости пропа над полом (из `size.h`) у мест с `lie`, `sit`, `stand_on`.
- Для `lie`:
  - `at` — центр верхней плоскости;
  - `yaw` — вдоль длинной стороны, голова к изголовью (изголовье — задняя сторона пропа, противоположная фронту);
  - `head` — точка головы в мире.
- Для `stand_on`: `at` — центр верха.
- `slots: {pose: n}`: у кровати и дивана `{lie: 1, sit: 2}`, у остальных по 1 на позу. `stand_at` и двери без лимита по-прежнему через боковую точку `SIDE_M`.
- `places.ts`: `resolveTouch` принимает желаемую позу. Если поза есть у места и слот свободен, слот бронируется. Если поза занята или её нет, берётся `stand_at` рядом (как сейчас «рядом»), и это пишется в предупреждения сцены.

- [x] красные тесты (Python): сцена-фикстура с `bed` (1.9×0.6×1.0, фронт +z), `stool` (0.3 м) и `sink` → у кровати `poses` `["lie","sit"]`, `top` 0.6±0.01, `yaw` вдоль длинной стороны, `head` у задней стороны; у табурета `["stand_on","sit"]`, `top` 0.3; у раковины `["stand_at"]`; у табурета 0.8 м нет `stand_on`
- [x] красные тесты (TS): два актёра просят `lie` на одной кровати → второй получает `sit` на той же кровати, если просил `sit`, иначе `stand_at` рядом; поза, которой нет у места, → `stand_at` и предупреждение; все слоты позы заняты, её просит третий → `stand_at` и предупреждение с id актёра
- [x] код; старые тесты `test_stage_*` и `stage-*` зелёные; гейт зелёный

## Н9. постановка: тело в позе без клипа и два тела не совмещаются

Зоны: `engine/src/runtime/stage/actors.ts`, `engine/src/runtime/stage/pose.ts` (новый), `engine/src/runtime/stage/places.ts`, `engine/src/runtime/stage/touch.ts` (`createToucher` управляет маршрутом; раздвигание применяется в нём каждый кадр после шага движения, по списку всех актёров из `actors.ts`), `engine/src/runtime/stage/anim.ts` и `life.ts` (только приём позы), новые `engine/test/stage-pose.test.ts`, `engine/test/stage-collide.test.ts`.

Клипов с позой нет (зевок лёжа и стойку на табурете снимем позже через Omni, парковка L30). Движок ставит позу сам.

Контракт `pose.ts`:
- `poseBody(root, pose, place)` — чистая функция над костями и корнем, как поза покоя без T (`9c95c8a`).
  - `lie`: корень повёрнут горизонтально вдоль `place.yaw`, спина на высоте `top`, голова у `place.head`, руки вдоль тела.
  - `stand_on`: стоячая поза покоя, корень на высоте `top`.
  - `sit`: поза-заготовка: бедро вперёд около 85°, колено около 85°, таз на высоте `top` у края.
  - `stand` / `stand_at`: как сейчас.
- Кости находятся по именам, как в `life.ts` (список имён с приоритетом). Без костей бедра или колена `sit` превращается в `stand_at`, это пишется в предупреждение.
- Слой жизни работает в любой позе. Лёжа и сидя перенос веса выключен, дыхание и голова остаются. Клип-глагол в позе, для которой он не снят (всё, кроме `stand`), не играется: вместо него идёт процедурный жест головой и грудью (кивок, зевок = голова назад и грудь вверх 1.5 с).

Контракт столкновений:
- У актёра капсула: радиус = 0.5 × max(ширина, глубина) его bbox в позе покоя, не меньше 0.12 м.
- Расстояние между центрами двух актёров в плоскости x–z всегда ≥ r1 + r2, пока допустимая точка существует (если её нет — узкий проход, стена: актёр останавливается до пересечения, факт пишется в `Stage.warnings()`), кроме глаголов касания (`hug`, `stroke`, `kiss`, `hold` — список в коде), для них ≥ r1 + r2 − 0.15.
- На старте сцены и при каждом `goto` и `come` конфликтная цель сдвигается на ближайшую свободную точку по кругу вокруг цели (шаг 15°, радиус r1 + r2 + 0.05) внутри комнаты и вне препятствий.
- В ходьбе действует раздвигание: проникновение исправляется за кадр сдвигом идущего, стоящий не двигается.

- [ ] красные тесты: `poseBody` `lie` на кровати `top` 0.6 → голова ниже 0.9 м и у `head` (±0.15 м), таз на `top` ± 0.1; `stand_on` `top` 0.3 → стопы на 0.3 ± 0.02; `sit` на риге без колена → `stand_at` + предупреждение; дыхание лёжа двигает грудь, таз не трогает
- [ ] красные тесты столкновений: два актёра со стартом в одной точке → расстояние ≥ r1 + r2; два актёра идут навстречу 600 кадров → ни в одном кадре расстояние < r1 + r2; `hug` подводит на r1 + r2 − 0.15 и не ближе; цель `goto`/`come` внутри препятствия, в стене или за границей комнаты → выбрана ближайшая свободная точка внутри комнаты, расстояние до других ≥ r1 + r2

## Н17. жест по ремарке голоса

Зоны: `engine/src/runtime/stage/anim.ts` (`pickClip`), `h0/dream/sim.py` (только `_book_step`: передать `remarks` бита в событие `line`), `engine/src/runtime/stage/index.ts` (только передача `remarks` в `clipForBeat`), тесты `engine/test/stage-gesture.test.ts` (новый).

Зачем (урок L73): в squid_live тело отвечало на то, как сказана реплика (`duo.html:205 pick`: вздох → пожать плечами, восторг → подпрыгнуть, грусть → поникнуть, привет → помахать). В движке `pickClip` видит только поле `gesture`; без него актёр говорит неподвижно.

Контракт:
- Если у бита есть `gesture`, он побеждает, как сейчас.
- Иначе жест выбирается по словам ремарок голоса и тексту реплики через таблицу; при нескольких совпавших сигналах берётся первое по порядку строк таблицы «слова → глагол» в коде (общая для всех персонажей, без веток по имени): приветствие → `wave`; sigh/tired/weary → `shrug`; excited/giddy/cheer → `jump`; sad/hurt/quiet → `droop`; stern/firm/offended → `armscross`; startled/gasp → `react`. Не совпало ничего → нет жеста (остаются кивки слоя жизни).
- Глагола нет в банке клипов актёра или поза не `stand` → процедурный жест головы и груди Н9 (`MEM parked-pose-clips-omni`).
- Случайный выбор допустим только среди нескольких клипов одного глагола и только через сид сцены: один и тот же бит даёт один и тот же жест (фильм воспроизводим).
