### Контракт камеры (для А3a и А3b)

`engine/src/runtime/stage/director.ts` — чистый. Вход: `{event: {kind: 'line'|'narrator'|'walk'|'tick', speaker?: string, durationS?: number, shot?: string, dt: number}, actors: {name, pos: [x,z], yaw, height, level: string|null, room: string|null, walking: boolean}[], room: {outline: [x,z][], ceiling: number, open: boolean}, rng: () => number}` — `index.ts` собирает его для комнаты говорящего (`room` актёра = `roomAt(pos, level)`; актёры с другим `room`/`level` в `actors` не передаются). Выход: `{plan: string, cam: [x,y,z], look: [x,y,z]}`. Состояние (прошлый план, счётчик реплик, `side`, отложенные склейки) живёт в объекте `createDirector(rng)`. Банк 8 планов как в `duo.html`: `ots` (через плечо слушателя), `close`, `two`, `wide`, `orbit`, `dolly`, `low`, `follow`.

Выбор плана — первое сработавшее правило по порядку:
1. поле бита `shot` (если это имя из банка) — берётся как есть, даже если совпадает с прошлым планом;
2. кто-то идёт → `follow` за идущим, если идёт ровно один; идут двое и больше → `wide`;
3. первая реплика сцены → `wide`;
4. реплика рассказчика → `two`, если все актёры комнаты в пределах 4 м друг от друга, иначе `wide`;
5. каждая пятая реплика (считаются все `line` и `narrator`, склейки-реакции не считаются) → `two`/`orbit`/`wide`;
6. остальное — из банка через `rng`.

Правила 1–4 детерминированы и повтор допускают; в правилах 5–6 тот же план два раза подряд нельзя (выбирается следующий из пула). Одна склейка на реплику. Слушатель — ближайший к говорящему другой актёр комнаты; у `narrator` слушателя и реакции нет; без слушателя (один актёр) нет `ots`/`two`/реакций, пул правила 6 сужается до `wide`/`close`/`follow`. Реплика (`line`) длиннее 7 с (не `orbit`/`dolly`) → на 45% склейка на `close` слушателя (реакция), на 75% обратно `ots`; склейки отменяются, если пришла новая реплика. `low` только если говорящий выше слушателя (иначе у Мирай 0.95 м камера уйдёт в пол).

Кадр плана:
- **правило 180°** (всё в плоскости XZ): ось `a` = единичный вектор от актёра с меньшим именем (по алфавиту) к актёру с большим — не от говорящего к слушателю, поэтому смена говорящего её не переворачивает. Нормаль `n = (−a.z, a.x)`, середина `m` = середина пары. Сторона `side = sign((центр_комнаты − m)·n)` (0 → `+1`), для двора центр = центр outline. Камера любого плана кроме `orbit` стоит так, что `sign((cam − m)·n) == side`. `side` пересчитывается только когда угол между текущей `a` и `a`, на которой `side` был выбран, превысил 90°. `orbit` правило не проверяет (по построению пересекает ось);
- высота глаз и `close` от роста говорящего (`h × 0.8`), не константа 1.5 м;
- `close`/`ots` — со стороны лица: угол между взглядом актёра и направлением на камеру ≤ 60°;
- `wide` строится по рамке актёров (+ запас 1.5–2 м; дистанция камеры такая, что рамка вписывается в вертикальный FOV, измерение — полная высота самого высокого актёра на расстоянии до самого дальнего от камеры актёра), а не по рамке места (на лугу ~20×20 м рамка места делала героев точками на горизонте);
- каждый кадр камеры — внутри комнаты: `clampCamera` + `snapInside` (уже есть, F31); если `snapInside` не нашёл точку внутри outline — запасной кадр: камера в середине пары актёров, затем шагами по 0.25 м к центру комнаты, пока точка не окажется внутри outline с отступом 0.3 м (до 40 шагов), на высоте глаз; если и так нет (комната уже 0.6 м) — просто центр комнаты; исключений наружу нет; **открытая** комната (`open: true`) — потолок камеры 3.5 м вместо 2.7, «внутри» = внутри outline двора;
- один актёр → `wide`/`close`/`follow` (без оси, без `ots`/`two`); актёры в одной точке (< 0.3 м) → ось по взгляду говорящего;
- внутри плана камера плавно следит (`1 − e^{−4·dt}`), склейка — прыжок.

`index.ts` берёт план из `director.ts` вместо таймера `talker ? close : …`. `directShot` остаётся (на него опираются старые тесты) или становится частным случаем — старые тесты зелёные.

## А1. cast: персонаж с клипами (путь A)

Зоны: `h0/make/cast.py`, `h0/make/stage.py`, `h0/make/testdata/cast_clips/**`, `h0/make/test_cast_clips.py` (новый), `h0/make/test_cast.py` (только дополнять: старые тесты не менять), `h0/make/testkit.py`.

Контракт `cast.src/cast.json` (хозяин кладёт файлы, стадия только проверяет и копирует в `cast/`):
```json
{"Mama": {"glb": "mama/body.glb", "height_m": 1.65, "voice": "woman", "sex": "female", "look": "kind cat mother",
          "clips": {"wake": "mama/wake.glb", "hug": "mama/hug.glb"},
          "idle": "wake@0", "verbs": {"hug": ["hug", "hugged", "hold", "held"]}}}
```
- `clips` — необязательная карта «имя клипа → GLB». Клип — **первая** анимация файла (в наших GLB она называется `rigAction`); имя клипа берётся из ключа карты, не из файла. Если `clips` заданы, анимации самого `glb` клипами не считаются (наше тело — один из клип-GLB, его `rigAction` — не клип).
- Имена клипов: `^[a-z][a-z0-9_]{0,31}$`. Суффиксы вида `_s1` хозяин срезает сам, стадия их не угадывает.
- `idle`: имя клипа (`"idle"`, играть по кругу) или `"<клип>@<сек>"` (застывшая поза этого кадра). Нет поля и нет клипа `idle` → `"<первый клип по алфавиту>@0"`. Нет клипов вообще → поле не пишется (персонаж статичен, как сейчас).
- `verbs` — необязательная карта «клип → слова-триггеры» для А2. Без неё — словарь по умолчанию (А2).

Проверки `check_cast` (каждая ошибка — строка `<who>.<поле>: …`, ни одного исключения наружу):
- клип-GLB читается тем же `_glb_ok`, что и `glb`;
- в клип-GLB есть ≥1 анимация, у неё ≥1 канал, длительность > 0 (максимум `max[0]` по input-аксессорам семплеров; по спецификации glTF `min`/`max` у input-аксессора анимации обязательны, поэтому данные буфера не декодируем: нет `max` → ошибка `<who>.clips.<имя>: sampler input has no max`);
- скелет совпадает с телом: множество имён суставов `skins[0].joints → nodes[].name` клипа ⊆ множеству тела. Тело без `skins` при непустых `clips` — ошибка `<who>.glb: no skin, clips need a skinned body`;
- каналы клипа целятся в узлы с именами (без имени канал нельзя перенести на тело) — иначе ошибка с номером канала;
- `idle` ссылается на существующий клип; `@сек` — число в [0, длительность клипа];
- путь клипа внутри `cast.src/` (как `glb` сейчас: `..`, абсолютные пути, симлинки наружу — ошибка);
- одинаковые файлы под разными ключами допустимы; один и тот же файл как `glb` и как клип — допустим.

Стадия `cast` уже копирует `cast.src/` в `cast/` (`run_cast`, `copytree`) и уже хэширует все файлы `cast.src` — это не переписывать, а закрепить тестом. `cast/cast.json` несёт `clips`, `idle`, `verbs` как есть (пути относительно `cast/`). `stage.json` уже ссылается на него полем `cast` (`stage.py:241`), а рантайм читает этот файл сам (`index.ts`: `fetch(new URL(stage.cast, runBase))`, клип-URL строится от `castUrl`). Формат `stage.json` не меняется; `stage.py` правится только если тест покажет, что поля теряются (персонаж без `clips` работает как раньше).

Фикстура: `h0/make/testdata/cast_clips/` — крошечные GLB (тело: 3 кости + скин + треугольник; клипы `wake`, `hug`; «чужой» клип с костью `tail`; клип без анимации; клип с нулевой длительностью; тело без скина). ## А2. рантайм: микшер, кроссфейд, клип по смыслу строки

Зоны: `engine/src/runtime/stage/anim.ts` (новый), `engine/src/runtime/stage/actors.ts`, `engine/src/runtime/stage/index.ts`, `engine/test/stage-anim*.test.ts` (новые).

`anim.ts` — чистый модуль без DOM и сети:
- `createAnimator(root: Object3D, clips: Record<string, AnimationClip>, opts: {idle?: string, fade?: number})` → `{play(name, {once?}), update(dt), current(): string, has(name)}`. Один `AnimationMixer` на персонажа.
- **Перенос клипа на тело по имени кости:** треки, чьих костей нет в теле, выбрасываются (лог один раз на клип), клип без единого трека → не регистрируется.
- **Голова калибровки (настоящий баг, на живом прогоне мама каждые 10 с встаёт в Т):** у каждого клипа мокапа первые 0.5–2 с — поза калибровки (плечи 0–10° от бинда; у `Mama/wake` 2 с), и луп с нуля возвращает актёра в Т. При регистрации клипа найти первый кадр, где **обе** кости `/upperarm_(l|r)/i` отклонены от своей bind-позы на ≥ 30° (bind-поза = `bone.quaternion` костей `root`, снятый один раз в `createAnimator` до первого `update`; в тестовой фикстуре кости создаются с заданным покоем), и отрезать всё до него; луп начинается с этой точки, `"клип@сек"` в `idle` отсчитывается от неё. Нет таких костей или порог не достигнут ни разу → клип без обрезки + одно предупреждение.
- **Ходьба на месте:** у треков `.position` корня (`/pelvis|root|hips/i` или кость-корень скелета) X и Z замораживаются на первом кадре (после обрезки); Y остаётся (прыжок, падение). Положение задаёт `walk`/`path`, не клип (урок duo.html и `research/anim_engine_notes.md`).
- **Кроссфейд** 0.15 с по умолчанию (4–5 кадров при 30 fps; урок «модель щёлкает на стыке — кроссфейд 3–5 кадров»). Повторный `play` того же клипа не перезапускает его.
- `once` клип играет один раз и возвращается в idle кроссфейдом, а не застывает на последнем кадре.
- **idle:** клип по кругу либо застывшая поза `"клип@сек"` (action с `timeScale = 0` на этом времени). Нет idle → поза кадра 0 первого клипа, **никогда** bind/T-pose (тела из Tripo стоят в T-позе).
- Нет клипа → idle + `console.warn` один раз на пару (персонаж, имя), не исключение.
- `pickClip(text: string, who: string | null, cast, aliases = {})` → `{who, clip} | null`: словарь «слово → клип» (по умолчанию: `wake`←wake/woke/waking; `hug`←hug/hugged/held/hold; `flick`←flick/flicked/splash/drip; `stroke`←stroke/stroked/pat/patted; `leap`←leap/jump/jumped/ran/run; `fall`←fall/fell/whoops/tumble; `sit`←sat/sit/climbed; `walk`←walk/walked) плюс `cast[who].verbs`. Кто делает: последнее имя персонажа или алиас **перед** глаголом в той же фразе; в реплике — говорящий; `who === null` (рассказчик) — подлежащее ищется по имени/алиасу перед глаголом, как выше, без подстановки говорящего. Регэкспы с `u`-флагом и границами слов, как в `stage-regex-unicode.test.ts`. Клипа у этого персонажа нет → `null`. `aliases: Record<string, string>` — «алиас в нижнем регистре → имя персонажа из `cast`» (например `{"mum": "Mama"}`); необязателен (в `cast.json` их пока нет). Совпадение алиаса и имени персонажа — имя главнее.
- `clipForBeat(beat, cast, aliases = {})` → `{who, clip} | null`: поле бита `gesture` (строка; оно уже едет на событии `line`, см. `h0/dream/sim.py`, поиск по `"gesture"`) побеждает `pickClip`: если `gesture` — ключ `cast[who].clips` (точное совпадение без регистра), клип = он; иначе `pickClip(gesture, who, cast, aliases)`; если и это `null` (жест без совпадения) — `pickClip` по тексту реплики. Формат `verbs` в `cast.json`: «клип → слова» (как в А1), `pickClip` разворачивает в «слово → клип» и добавляет к словарю по умолчанию, слова персонажа главнее. Для `narrator` — только `pickClip(text, null, …)`. `index.ts` вызывает только её, вся логика — здесь, чтобы её проверял node-тест.

`actors.ts`: `createActor` получает `clips` (URL-ы) и `idle`; грузит тело через `loadGlb` как сейчас, клип-GLB — параллельно своим `GLTFLoader` и берёт из них только `animations` (`loadGlb` и `assets.ts` не менять: `loadGlb` возвращает одну сцену и масштабирует её под рамку). Клип, который не загрузился, пропускается с предупреждением; тело не загрузилось → коробка, как сейчас. `update(dt)` двигает микшер. Ходьба по пути включает `walk`, если он есть, иначе idle; конец пути → idle. Путь приходит так же, как сейчас: события `walk`/`touch` в `index.ts` вызывают `actor.go(path, yaw, act, ys?)` (сигнатура не меняется). Начало и конец пути актёр определяет сам: в `update(dt)` сравнивает `moving()` с прошлым кадром — `false→true` → `animator.play('walk')` (если клипа нет — idle), `true→false` → `animator.play(idle)`.

## А4. make: книга ждёт зрителя, refs без картинок

Зоны: `h0/make/play.py`, `h0/dream/server.py`, `h0/make/refs/__init__.py`, `h0/make/test_play_wait.py` (новый), `h0/make/test_refs_warn.py` (новый).

Найдено на живом прогоне Кошакана (хозяин, 01:50).

**Книга ждёт зрителя:** `make.play` стартует сим сразу и гасит статику по концу сцены; страница, открытая позже, видит конец сцены или 404 на клипах. Нужен флаг `--wait-viewer` (по умолчанию включён, когда не `--fake`; выключается `--no-wait-viewer`). Цепочка: `main()` в `play.py` → `play(..., wait_viewer=True, wait_timeout=120)` → `sim.run(..., on_sim=...)`: `sim.run` уже вызывает `on_sim(sim)` после `viewer.start()` и до `sim.run(...)`, поэтому `sim.py` менять не надо — `play()` передаёт `on_sim=lambda sim: sim.viewer.wait_client(wait_timeout)`. `Viewer` (`server.py`) получает `self.client_connected = threading.Event()`, обработчик SSE `_events` вызывает `.set()` сразу после `end_headers()`, и метод `wait_client(timeout) -> bool` (`Event.wait`). Не пришёл за `wait_timeout` (120 с) → строка `WARN no viewer after <N>s, starting anyway` в stdout и старт. После `play()` в `main()` при `wait_viewer` процесс явно блокируется `hold()` (по умолчанию `threading.Event().wait()` с перехватом `KeyboardInterrupt`; `main(argv, hold=...)` принимает подмену для теста), затем `finally: srv.shutdown()`. `wait_viewer` без `serve` (или с `--fake`) ожидания не создаёт и молча игнорируется (`sim.viewer` нет); в `main()` при живом запуске `serve` всегда задан. С `--fake` ожидания нет (гейт не ждёт). Тест — без сети наружу, только локальный сокет: фейковый клиент подключается через 2 с, первое событие приходит после подключения; таймаут (в тесте — короткий, через параметр) → старт и строка предупреждения.

**refs, тихо пусто:** для частной книги веб-поиск давал 0 картинок, и мир строился вслепую без предупреждения. Сцена книги теперь несёт `refs`/`ref_cues` (`book.json`), стадия refs берёт их вместо поиска (`refs.book_local`, тест `test_refs_book_local.py`, уже починено хозяином — не трогать). Добавка: `<place>` — id места из `brief.places[].id` (ключ слота в `run_refs`); «0 картинок» — у слота после стадии нет ни одной записи с `kept: true` (пустой поиск, все скачивания отброшены, не нашлось локальных). Для таких слотов (включая локальные слоты без картинок; ветка «нет запроса» исключена) `run_refs` копит список и печатает `WARN no refs for <place>` в stdout (он попадает в лог стадии) и пишет список id в `refs.json` ключом `warnings`; слоты персонажей без запроса сюда не входят. `core.py` и `make.json` не трогать.

- [x] красные тесты `test_play_wait.py` (ждёт клиента; таймаут → старт с предупреждением; `--fake` не ждёт) и `test_refs_warn.py` (фикстуры: (а) провайдер возвращает пустой список; (б) кандидаты есть, но `loader` отклоняет их все; (в) локальный слот (`local`) с пустым списком путей; (г) контроль: слот с хотя бы одной принятой картинкой; место без картинок → `WARN no refs for <place>` в stdout и id в `refs.json["warnings"]`; место с картинками → без строки и `warnings` пуст)
