# Реестр уроков и парковок

Единственное место, где живёт статус каждого урока и каждой отложенной идеи. Подробности остаются в источниках:
- `EN` — `research/engine_notes.md`, бывший `anymove/runs/squidward/ENGINE_NOTES.md`;
- `TR` — `research/llm_friction.md`;
- `MEM` — память Claude;
- `SQ` — `h0/squid_live`.

## Правила (с 2026-11-01)

1. **У урока всегда есть статус, иначе он не считается записанным.** Новый урок попадает сюда в тот же день, а не только в заметки.
2. **Статусы:**
   - `спека` — фаза в файле спеки, указана;
   - `план` — нужен в ближайшей спеке, фазы ещё нет;
   - `долг` — сделать после сабмита;
   - `парк` — отложено пользователем, без сроков;
   - `готово` — коммит или файл, где это сделано;
   - `отказ` — решили не делать, с причиной.
3. **Любая новая спека начинается с прохода по `план` и `долг`.** Что берём, получает фазу (`спека`), остальное остаётся.
4. **`готово` переезжает в архив внизу одной строкой с коммитом.** Открытая часть остаётся короткой.
5. **Урок из эксперимента (скрипт, `squid_live`, ручная сборка) обязательно получает ответ на вопрос «как это делает движок».** Если ответа нет, это `план`.
