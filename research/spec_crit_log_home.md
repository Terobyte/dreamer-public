# Лог критики спеки Dreamer Home (11-04)

Критик luna (codex gpt-6-luna, read-only), три линзы за раунд: 1 — соответствие репозиторию (с раунда 3 — корректность кода), 2 — однозначность и проверяемость (с раунда 3 — спека против кода), 3 — достигает ли цели хозяина (сабмит сегодня, видео и репо). Правки мои. Хозяин спал; цель от хозяина: «ui/ux для сабмита: готовые сцены книга/фристайл + создать свою; спек → критика luna → реализация → тест → сабмит».

## Раунд 1 → 0.2 (оценки 6 / 5 / 4)
Принято: общий статус сборки выводится из стадий `make.json` и кода выхода (общего поля нет); абсолютный корень `meta/runs`; два независимых слота (Scene, Build); URL `make.play` печатается до `play()` → проверка жизни; stderr в файл, stdout отдельным потоком; контракт ошибок по каждому эндпоинту; WAV 16 кГц mono s16 через `wavOf` из `dictate.js`; проверка страницы по `dist_of`; неготовые карточки скрыты; визуальная приёмка; cut line (обязательно / должно / хорошо бы); один дедлайн 20:00 ET. Найдено мной по ходу: seed-режим не доносит каст (`sim.seed_start` берёт актёров режиссёра) → Create через книжный режим: Spark пишет главу-мини-книгу с полем `room`, `make --book … --world …`; `--world` линкует готовый мир. Отклонено наполовину: «Кошакан плохо выглядит» (`PROGRESS` 11-01 про старые миры по комнатам; новый дом `world_pic` проверен кадрами).

## Раунд 2 → 0.3 (оценки 6 / 4 / 3)
Большая часть — расхождения с черновиком кода, который на момент чтения ещё не дошёл до 0.2 (глава, `/api/session`, проверка жизни) — к раунду 3 сделано. Принято: `MAX_DOLLARS` 1; ошибки GET тоже JSON; атомарный захват слота сборки (`create_mu`); один повтор запуска при `Address already in use`; явный список корней `meta`, `../anymove`, `../meta-place`; семантика времени (идущая стадия растёт, общее замирает на последнем `finished`); статусы стадий `make` только running/ok/failed (`reason: budget`); флаг `create` в каталоге; мир готов только с `dist/geometry.json` и кастом без ошибок `check_cast`; GET страницы перед 200; при смерти после URL группа гасится; `paras` полуинтервал `[0, n]`. Честное замечание линзы 3: ассеты сцен вне репо — в README Home записано, что чистый клон работает только `--fake`.

## Реализация и живой прогон (между раундами 2 и 3)
Коммит `286390b8`. Вживую: книга (Кошакан ×2, Шерлок), фристайл 2 мин, двор, Create «котёнок» 3 мин 04 с / $0.07. Найдено вживую: теги голоса в субтитрах фристайла и русская кнопка → `cleanSubtitle` и английские подписи в движке, рантайм дома Кошакана пересобран. Обложки Шерлока пропали (другая сессия пересняла `film/`) → обложки живут в `h0/home/static/covers/`.

## Раунд 3 → 1.0 (оценки 5 / 5 / 6; тесты у критика не шли: песочница без tmp и localhost)
Принято: `_kill_group` ждёт пустую группу и добивает SIGKILL, в том числе когда лидер уже умер (тест: внук игнорирует SIGTERM); ошибка старта `make` в статусе; `Build.stop` ждёт поток главы; одна выборка `current()` в `/api/scenes` (гонка → 500); таймер главы идёт; кривые кавычки отклоняются; Content-Type — точный media type; кэш `check_cast` по всем файлам каста; гонка микрофона (отпустил до разрешения); «⚡ switching…»; `create:false` прячет форму (тест 403); заголовок «Step inside a story, or write the next one.», плейсхолдер «For example», подсказка у выключенной кнопки; e2e: Book → `mode=book`, три вкладки, ≥3 целых карточки, кадр сборки на всю страницу. Спека приведена к сделанному виду (цвета, кредиты сверху). Не принято: отменять идущий вызов Spark при выходе (нет отмены у `spark_call`; поток ждётся 5 с и не запускает `make`). Остаётся: Шерлок со старым рантаймом (русская кнопка) до слияния `meta-place`.
